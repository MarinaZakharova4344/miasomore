# Фотографии

- `restaurant.webp`, `hall.webp`, `showcase.webp` — фото зала MясоMore.
- `shop.webp`, `delivery.webp`, `menu/*`, `shop/*` — временные фото с [Pexels](https://www.pexels.com/license/) (бесплатно, указывать автора не обязательно). Замените на съёмку своих блюд и продуктов, когда она будет.

Чтобы заменить фото, положите новый файл с тем же именем (WebP, квадрат для меню и товаров, 4:5 для карточек направлений). Путь для конкретного блюда или товара задаётся полем `img` в `js/data.js`. Если у позиции нет `img` или файл не найден, показывается тёмная заглушка с иконкой.

Меню в PDF положите в `assets/menu.pdf`.
