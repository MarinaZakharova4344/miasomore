# Фотографии

Все фото на сайте — собственные фото ресторана MясоMore.

- `hall.webp`, `restaurant.webp`, `showcase.webp` — зал и витрина.
- `menu/<id>.webp` — миниатюра блюда (квадрат 360×360, общий план на синем фоне).
- `menu/<id>-lg.webp` — крупный план, открывается по клику на фото в меню.
- `oysters-shop.webp`, `oysters.webp` — устрицы для карточки «Магазин» и раздела «О нас».
- `delivery-map.webp` — карта Петербурга для карточки «Доставка» (данные © участники OpenStreetMap).
- `dishes.webp` — антипасти в разделе «О нас».

`<id>` — это id блюда в `js/data.js`. Чтобы добавить фото блюду, положите оба файла (`<id>.webp` и `<id>-lg.webp`) в `menu/` и пропишите блюду `img: P + '<id>.webp'`.

Товары магазина показываются без фото. Если появится съёмка товаров, у товара в `js/data.js` можно указать поле `img`.

Меню в PDF положите в `assets/menu.pdf`.
