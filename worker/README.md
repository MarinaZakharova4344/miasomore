# Заявки на бронь в Telegram

Схема: форма на сайте → Cloudflare Worker → сообщение в Telegram.
Токен бота хранится только в Cloudflare, на сайте и в репозитории его нет.

Пример сообщения:

```
🍽 Новая заявка на бронь

📅 24.10.2026 (сб), 19:30
👥 Гостей: 4
👤 Анна
📞 +79052226272
💬 У окна

Перезвоните гостю, чтобы подтвердить стол.
```

## 1. Создать бота
1. В Telegram откройте [@BotFather](https://t.me/BotFather) и отправьте `/newbot`.
2. Придумайте имя (например, «MясоMore Брони») и адрес, который заканчивается на `bot` (например, `miasomore_booking_bot`).
3. BotFather пришлёт **токен** вида `1234567890:AAH...`. Никому его не показывайте и не вставляйте в код сайта.

## 2. Узнать id чата
**Если заявки нужны лично вам:**
1. Найдите своего бота в Telegram и нажмите **Start** (или отправьте ему любое сообщение).
2. Откройте в браузере `https://api.telegram.org/bot<ТОКЕН>/getUpdates`, подставив свой токен.
3. Найдите `"chat":{"id":123456789` — это число и есть **id чата**.

**Если заявки нужны в рабочую группу (администраторам):**
1. Добавьте бота в группу и напишите в группе любое сообщение.
2. Откройте ту же ссылку `getUpdates`. У группы id отрицательный, например `-1001234567890`.

## 3. Создать Worker в Cloudflare
1. Зарегистрируйтесь на <https://dash.cloudflare.com> (бесплатно).
2. **Workers & Pages → Create → Create Worker** (шаблон «Hello World»), назовите `miasomore-booking`, нажмите **Deploy**.
3. Нажмите **Edit code**, удалите всё и вставьте содержимое файла `worker/booking-worker.js`. Нажмите **Deploy**.
4. Откройте **Settings → Variables and Secrets** и добавьте три переменные:

   | Имя | Тип | Значение |
   |---|---|---|
   | `BOT_TOKEN` | **Secret** | токен из шага 1 |
   | `CHAT_ID` | Text | id чата из шага 2 |
   | `ALLOWED_ORIGINS` | Text | `https://marinazakharova4344.github.io` |

5. Скопируйте адрес Worker'а вида `https://miasomore-booking.<ваше-имя>.workers.dev`.

## 4. Подключить сайт
Вставьте адрес Worker'а в `js/config.js`:

```js
window.MM_CONFIG = {
  bookingEndpoint: 'https://miasomore-booking.<ваше-имя>.workers.dev',
};
```

Отправьте изменения на GitHub и через пару минут заполните форму на сайте — сообщение придёт в Telegram.

## Защита
- Worker принимает заявки только с адресов из `ALLOWED_ORIGINS`.
- Поля проверяются на сервере: имя, телефон из 11 цифр, дата, время, от 1 до 20 гостей.
- Скрытое поле-ловушка отсеивает простых спам-ботов.
- Если Telegram недоступен, гость увидит просьбу позвонить по телефону, и заявка не потеряется молча.

Бесплатного тарифа Cloudflare (100 000 запросов в день) хватит с огромным запасом.
Если появится свой домен, добавьте его в `ALLOWED_ORIGINS` через запятую.
